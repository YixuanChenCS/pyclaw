# Contributing results

Contributions of benchmark results are welcome!
See the
[benchmark README](https://github.com/Pyclaw-AI/pyclaw/blob/main/benchmark/README.md)
for information on running pyclaw's code editing benchmarks.
Submit results by opening a PR with edits to the
[benchmark results data files](https://github.com/Pyclaw-AI/pyclaw/blob/main/pyclaw/website/_data/).
